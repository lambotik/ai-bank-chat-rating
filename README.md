## 🎯 Описание проекта

Система предназначена для автоматической оценки качества обслуживания в чатах банка. Она анализирует диалоги между
клиентами и сотрудниками поддержки, используя локально развернутые LLM модели через Ollama, и выставляет оценки по
различным критериям.

### Ключевые возможности:

- Анализ диалогов из Excel файлов
- Оценка по 4 ключевым критериям
- Классификация диалогов по тематическим группам
- Расчет метрик времени обслуживания (AHT)
- Автономный режим при отсутствии Ollama
- Экспорт результатов в JSON и CSV

## 🔧 Установка и настройка

### 1. Установка Ollama

Ollama - это инструмент для запуска LLM моделей локально.

#### Windows:

1. Скачайте установщик с официального сайта: [https://ollama.com/download/windows](https://ollama.com/download/windows)
2. Запустите установщик и следуйте инструкциям
3. После установки Ollama автоматически запустится как фоновый сервис

#### Linux (Ubuntu/Debian):

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

#### macOS:

```bash
brew install ollama
```

---

### 2. Загрузка моделей

После установки Ollama, загрузите необходимые модели. Для работы системы рекомендуется загрузить несколько моделей для
сравнения результатов:

```bash
# Запустите сервер Ollama (если не запущен)
ollama serve

# В отдельном терминале загрузите модели:
ollama pull llama3.2:latest      # Meta Llama 3.2 (рекомендуется)
ollama pull phi:2.7b              # Microsoft Phi-2 (легковесная)
ollama pull mistral:7b            # Mistral 7B
ollama pull gemma:2b              # Google Gemma
ollama pull qwen2.5:7b            # Alibaba Qwen 2.5
ollama pull tinyllama:1.1b        # TinyLlama (ультра-легкая)
ollama pull deepseek-coder:1.3b   # DeepSeek Coder
ollama pull deepseek-r1:8b        # DeepSeek R1
```

#### Рекомендуемые модели для оценки:

- llama3.2:latest - лучший баланс качества и скорости
- phi:2.7b - очень быстрая, хороша для тестирования
- mistral:7b - высокая точность, требует больше ресурсов
- qwen2.5:7b
- tinyllama:1.1b
- deepseek-coder:1.3b
- deepseek-r1:8b

#### Проверьте загруженные модели:

```bash
ollama list
```

### Результаты

#### После обработки программа создаст два файла:

- results.json - результаты в формате JSON
- results.csv - результаты в формате CSV для анализа в Excel

### 📊 Форматы данных

#### Входной файл (Excel)

Должен содержать следующие колонки:

- id диалога - уникальный идентификатор
- ФИО клиента - имя клиента
- Категория - категория обращения
- Тематика - тема диалога
- Подтематика - подтема
- Оценка - оценка клиента (если есть)
- Длительность диалога (сек) - время в секундах
- Среднее время ответа оператора (сек) - метрика скорости ответа

### 📏 Критерии оценки

#### Система оценивает диалоги по 4 критериям (1-5 баллов):

- client_satisfaction - удовлетворенность клиента
- issue_resolution - решение проблемы
- customer_orientation - клиентоориентированность
- operator_courtesy - вежливость оператора

#### Шкала оценок:

- 5 - проблема полностью решена, быстро и вежливо, клиент благодарит
- 4 - проблема решена, но были небольшие заминки или общие ответы
- 3 - частичное решение или не очень удобное общение
- 2 - не решено, но попытки были, медленная реакция
- 1 - игнор, некорректные ответы, проблема не решена

### Группы диалогов:

- Группа 1: обращения, связанные с блокировками, страхованием, ФНС, арестами
- Группа 2: обычные обращения (по умолчанию)
- Группа 3: обращения по 115-ФЗ, долям, перепланировкам

#### Изменение промпта в коде

Отредактируйте ```DEFAULT_TEMPLATE``` в ```services/prompt_template.py```

Настройка параметров в ```config/settings.py```

```python
@dataclass
class OllamaSettings:
    base_url: str = "http://localhost:11434"
    model: str = "phi:2.7b"  # Модель по умолчанию
    timeout: int = 60  # Таймаут запроса
    temperature: float = 0.1  # Температура генерации
    max_retries: int = 3  # Попытки при ошибке
```

### 🔍 Устранение неполадок

#### Ошибка: Не удается подключиться к Ollama

Решение:

```bash
# Проверьте, запущен ли сервер
ollama serve

# В другом терминале проверьте доступность
curl http://localhost:11434/api/tags
```

#### Ошибка: Модель не найдена

Решение:

```bash
# Посмотрите доступные модели
ollama list

# Загрузите нужную модель
ollama pull llama3.2:latest
```

---

#### Ошибка: Не хватает памяти

Решение:

- Используйте более легкие модели (phi:2.7b, gemma:2b)
- Уменьшите количество одновременно обрабатываемых диалогов
- Закройте другие приложения

---

#### Ошибка: Неправильный JSON в ответе модели

Система автоматически использует fallback режим с оценкой на основе метаданных. Для улучшения качества:

- Используйте более качественные модели (llama3.2, mistral)
- Понизьте температуру генерации в настройках

---

### Проблемы с Excel файлом

Решение:

- Убедитесь, что файл не открыт в Excel
- Проверьте правильность названий колонок
- Используйте формат .xlsx (не .xls)
